Mergen SDK — Maven repository

Android SDK для сканирования и верификации ID-карт КР. Аутентификация не требуется.

Подключение

settings.gradle.kts

dependencyResolutionManagement {
    repositories {
        maven {
            url = uri("https://danielphp01.github.io/mergen-maven/")
            content { includeGroup("com.mergen") }
        }
    }
}

app/build.gradle

implementation 'com.mergen:mergen-sdk:2.6.1'

content { includeGroup("com.mergen") } не обязателен, но избавляет Gradle от лишних запросов к этому репозиторию за чужими артефактами.

Зеркало

Те же артефакты публикуются в GitHub Packages (maven.pkg.github.com/DanielPHP01/MergenSDK-Android), но тот реестр требует classic PAT даже для публичных пакетов. Этот репозиторий существует, чтобы интеграторам не нужны были токены.
